Answer-flip patterns

For each sample we look up the gpt-5-nano per-window decision sequence (one A/B call after every tool response). The pattern below is the run-length-compressed sequence — so a sample that "thought" A after tool 1, A after tool 2, then B after tool 3 shows up as A→B. Counts use only samples that have at least one committed A/B decision; samples whose cache miss or whose every window was uncommitted are reported separately.

Each compare_similar_mols call returns 6 neighbors (3 labeled positive = class (B), 3 labeled negative = class (A)), each with its own similarity. The primary KNN vote is similarity-weighted over all 6 neighbors: vote = B iff Σ sim(positive) > Σ sim(negative). Obey = final answer letter matched the KNN vote. TDC convention: (B) = has-property (positive).
