Each compare_similar_mols call returns 6 neighbors (3 labeled positive = class (B), 3 labeled negative = class (A)), each with its own similarity. The primary KNN vote below is similarity-weighted over all 6 neighbors: vote = B iff Σ sim(positive) > Σ sim(negative). Alternative vote definitions — top-1 (single highest-sim neighbor) and top-3 majority — are plotted alongside so you can see how obey / retrieval-correctness rates change depending on how you define the vote. Obey = final answer letter matched the KNN vote. TDC convention: (B) = has-property (positive).
